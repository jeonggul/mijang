# MIJANG

미국 주식 매매 기록과 투자 회고 서비스입니다.

[포트폴리오 홈](https://github.com/jeonggul) · [소스 코드](https://github.com/jeonggul/mijang)

## 프로젝트 개요

**기간:** 2026.08–2026.09  
**구성:** 개인 프로젝트

매수·매도 내역과 투자 판단을 함께 기록하고, 원화 손익을 주가와 환율의 영향으로 나누어 확인하는 웹 서비스입니다. 투자 기록, 포트폴리오, 종목 정보와 투자 회고를 한 흐름에서 확인할 수 있도록 구성했습니다.

![MIJANG 대시보드](https://raw.githubusercontent.com/jeonggul/jeonggul/main/assets/mijang-dashboard.png)

화면의 금액은 시연 데이터이며 서비스 성과나 실제 투자 수익률을 의미하지 않습니다.

## 담당 범위

서비스 기획, 거래·보유 종목·손익 계산 설계와 구현, 웹 화면과 외부 데이터 연동, 테스트 및 AWS 배포를 수행했습니다.

## 사용 기술

Java 17 · Spring Boot 4.0.7 · MyBatis · MySQL 8 · Thymeleaf · JavaScript  
외부 시세 WebSocket · 브라우저 SSE · JUnit · AWS EC2 · Nginx · HTTPS

## 매매 기록과 투자 회고 기능

매수·매도 내역에 매매 이유와 목표가, 당시 심리를 함께 남기고, 회고 화면에서 이후 주가 추이와 비교하도록 구성했습니다. 기록한 판단을 돌아볼 수 있도록 거래 내역과 보유 수량, 손익 계산이 일치하는 데 신경 썼습니다.

과거 거래를 수정하면 최종 잔량은 양수여도 중간 시점에 초과 매도가 생길 수 있어, 거래를 시간순으로 재계산하며 최소 보유 수량을 검증했습니다. 거래 변경과 재계산은 하나의 트랜잭션으로 묶고 수량이 음수가 되면 되돌렸습니다. 손익은 BigDecimal로 계산하고 주가·환율 영향을 나누었으며, 거래 순서와 주식 분할 조건을 단위 테스트로 확인했습니다.

## 실시간 시세 연동과 구독 관리

Alpaca WebSocket으로 받은 체결 데이터를 SSE로 브라우저에 전달하도록 구성했습니다. 서버에서 시세를 보내는 단방향 흐름에 맞춰 SSE를 선택했습니다. 외부 API의 종목 구독 한도 안에서 여러 사용자가 같은 종목을 볼 수 있도록 중복 구독을 합치고 참조 횟수를 관리했습니다. 화면 표시용 실시간 시세와 손익 계산 기준인 일봉 종가는 구분했습니다.

## 배포 환경에서 해결한 문제

AWS EC2에 애플리케이션과 MySQL을 구성하고 Nginx를 통해 HTTPS로 연결했습니다. 초기 배포에서는 DB 스키마 차이로 로그인 오류가 발생해 애플리케이션이 요구하는 컬럼과 배포 DB의 구조를 대조하고 일치시켰습니다.

HTTPS 프록시 뒤에서 OAuth 콜백이 HTTP로 생성되는 문제는 전달 헤더 처리 설정과 등록된 콜백 주소를 맞추어 수정했습니다. 로컬 실행뿐 아니라 배포 환경의 DB 상태와 요청 경로도 함께 확인해야 한다는 점을 경험했습니다.

## 구현 결과

거래 이력 재계산, 주가·환율 손익 분리, 주식 분할 반영을 하나의 투자 기록 흐름에 적용했습니다. 계산 클래스와 거래 수정 관련 테스트를 갖추고, 서버 배포 과정에서 발생한 스키마 및 OAuth 연결 문제를 해결했습니다.

## 로컬 실행

Java 17과 MySQL 8이 필요합니다.

1. `src/main/resources/application-secret.properties.example`을 같은 폴더의 `application-secret.properties`로 복사하고 로컬 DB와 외부 API 설정을 입력합니다.
2. MySQL에 `mijang` 데이터베이스와 애플리케이션 사용자를 준비합니다.
3. 별도로 관리하는 DB 스키마와 필요한 마이그레이션을 날짜순으로 적용합니다. 해당 SQL 문서는 현재 저장소에 포함되어 있지 않아 별도 준비가 필요합니다.
4. 저장소 루트에서 아래 명령을 실행합니다.

```bash
./gradlew test
./gradlew bootRun
```

배치가 비활성화되어 있거나 시세·환율 데이터가 없는 로컬 환경에서는 일부 화면이 빈 상태 또는 대체 화면으로 표시될 수 있습니다. API 키와 비밀번호는 저장소에 올리지 않습니다.

본 프로젝트는 개인 학습 및 포트폴리오 목적이며, 투자 자문이나 금융 서비스 제공을 목적으로 하지 않습니다.
